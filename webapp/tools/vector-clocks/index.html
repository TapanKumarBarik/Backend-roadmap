The Math Behind Vector Clocks

Local Event Rule

Before node $i$ produces any internal event, it increments its own logical component in its vector clock: $V_i[i] \leftarrow V_i[i] + 1$.

Message Passing & Merge Rule

When sending, node $i$ increments $V_i[i]$ and attaches $V_i$ to the message. When receiving, node $j$ computes the component-wise maximum and increments its own clock: $V_j[k] \leftarrow \max(V_j[k], V_{msg}[k]), \forall k$, followed by $V_j[j] \leftarrow V_j[j] + 1$.

Happens-Before ($\le$)

$V_A \le V_B$ if and only if $\forall k, V_A[k] \le V_B[k]$. If $V_A \le V_B$ and $V_A \ne V_B$, event $A$ strictly preceded $B$ in the causal timeline ($A \to B$).

Concurrent Conflicts ($\parallel$)

If neither $V_A \le V_B$ nor $V_B \le V_A$ holds, the events are concurrent ($V_A \parallel V_B$). Distributed databases (e.g. DynamoDB shopping carts) return siblings to the client or invoke conflict resolution (CRDTs or Last-Write-Wins).
