How to work it out by hand

A prefix like /26 says the first 26 of the address’s 32 bits name the network, and the other 6 are for hosts. That leaves 26 = 64 addresses in the block, of which the first (the network address) and the last (the broadcast address) are not given to hosts, so 62 are usable.

To find the block of 192.168.1.130/26, use the block size. The mask is 255.255.255.192, so the block size in the last octet is 256 − 192 = 64. The blocks start at 0, 64, 128 and 192. The address ends in 130, which lies in the block that starts at 128: network 192.168.1.128, broadcast 192.168.1.191, hosts .129 to .190.

The calculator shows the same working for any block you type.
