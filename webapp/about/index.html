How the lessons are made

Much of the text on this site (the lessons, the quizzes, the exercises and their worked solutions) was drafted with the help of AI tools. That is fast, and it makes mistakes: a drafted page can state something false with complete confidence, and a second read does not catch everything. So no page here is guaranteed to be correct, and a page that does not say it was checked has not been checked line by line.

Many lessons have a “production war story” or an “incident post-mortem”. Unless a story names its source, treat it as a scenario written to teach one failure, and its numbers as illustrative. It is not a report of something that happened.

What is checked by machine

On every change to the site, each coding and SQL problem in the Practice Center has its model solution run against its tests, every published address is checked to still work, and the arithmetic behind each tool in the Network Lab has its own tests. These checks find broken code and broken links. They cannot find a lesson that is wrong in prose, which is why corrections matter.

When something is wrong

If you find a mistake, write to %DEVELOPER_EMAIL%. It is fixed, and what was wrong and what changed is written on the corrections page, so you can see that fixes happen.
