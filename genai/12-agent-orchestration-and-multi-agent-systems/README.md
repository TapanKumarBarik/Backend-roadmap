# Track 12: Agent Orchestration & Multi-Agent Systems

When one agent isn't enough: the topologies (orchestrator-worker,
supervisor, hierarchical teams, swarm/handoff), how agents actually
communicate and share state, and how the major frameworks differ. Ends
honestly — multi-agent adds real cost and failure surface, and a large
part of this track is knowing when *not* to reach for it.
