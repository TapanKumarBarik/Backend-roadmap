# Neural Networks: Perceptrons → PyTorch → Vision, Sequences, Diffusion & Deployment

A ground-up curriculum on how neural networks work mathematically, how to build and train them reliably in PyTorch, and how modern deep architectures (CNNs, RNNs, VAEs, GANs, Diffusion, Graph Neural Networks) are engineered and optimized for production.

> **Build status:** All 7 tracks (68 modules) are outlined below with coming-soon module placeholders. Builds on [Machine Learning](../ml/README.md) and hands off directly into Transformer/LLM specialization in [GenAI Engineering](../genai/README.md).
