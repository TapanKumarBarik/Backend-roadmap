# Track: Interview Framework

How to structure 45 minutes: clarify, estimate, design, deep-dive, trade-offs, and what changes from senior to staff.

Part of **Phase 8** on the [YouTube playlist](https://www.youtube.com/playlist?list=PLCa3R_S2yPGI). Every lecture pairs a spoken walkthrough with a full 16-section written deep dive: architecture diagrams, mathematical models, 4-language production code tabs (`Go`, `TypeScript`, `Python`, `C#`), CLI verification workflows, 12 interview Q&As, and a one-page cheat sheet.

## How this track works

- Watch on YouTube (or from the site Videos page) first if you want the spoken version.
- Related deep modules elsewhere on the site (Backend, Learn, GenAI) may already host the same video beside a longer lesson. This track is the System Design short-lecture home for the same ideas.
- Use the [System Design Capacity Estimator](/tools/system-design-estimator/) alongside the estimation and bottleneck lessons.
