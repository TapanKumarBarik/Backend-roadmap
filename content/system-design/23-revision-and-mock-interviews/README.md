# Track: Revision and Mock Interviews

Numbers to memorize, topic revision sheets, weak-area loops and a final readiness checklist.

Part of **Phase 9** on the [YouTube playlist](https://www.youtube.com/playlist?list=PLY0eWXEZNuF8). Every lecture has a video, and every lesson in this track now has its written notes beneath it.

## How this track works

- Watch on YouTube (or from the site Videos page) first if you want the spoken version.
- Related deep modules elsewhere on the site (Backend, Learn, GenAI) may already host the same video beside a longer lesson. This track is the System Design short-lecture home for the same ideas.
- Each lesson covers quantitative foundations, decision matrices, Mermaid diagrams, 4-language executable tooling (Go, TypeScript, Python, C#), CLI verification, 12 Q&As, and a 1-page master cheat sheet.
