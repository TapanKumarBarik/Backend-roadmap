# Track 11: LangChain & LangGraph

The framework layer for everything track 10 just built by hand.
LangChain first (models, prompts, parsers, LCEL, chains, memory, tools,
retrievers), then LangGraph — which replaces linear chains with an
explicit state graph supporting cycles, branching, checkpointing and
human-in-the-loop, and which track 12's multi-agent systems run on top
of.
