# Track 02: Transformer Architecture

Every model in this curriculum — GPT, BERT, Llama, Claude, whichever
chat product you use daily — is a transformer. This track builds the
architecture up from the linear algebra you actually need (dot products,
nothing heavier), computes self-attention by hand on a tiny example, and
ends with you implementing a working mini-transformer in PyTorch. No
research-paper notation assumed.
