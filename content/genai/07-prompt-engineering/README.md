# Track 07: Prompt Engineering

The interface layer between "a model that predicts tokens" and "a system
that reliably does what you need." Covers the techniques that measurably
work (few-shot, chain-of-thought, structured output), how to organize
and version prompts like code, and — critically for anything that touches
untrusted input — prompt injection and how to defend against it.
