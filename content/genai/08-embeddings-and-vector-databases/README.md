# Track 08: Embeddings & Vector Databases

How text becomes a vector, what "similarity" means geometrically, how to
split real documents into retrievable chunks, and how approximate
nearest-neighbor search makes similarity search fast at scale. The
direct prerequisite for track 09 (RAG) — most RAG failures are actually
embedding or chunking failures.
