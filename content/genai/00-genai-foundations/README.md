# Track 00: GenAI Foundations

Before touching an API or a library, get the concepts straight: what
"generative AI" actually means, how the field arrived at today's large
language models, what these systems can and can't reliably do, and how
the pieces you'll learn in later tracks (tokens, transformers, RAG,
agents, MCP) fit into one coherent stack. This track is conceptual by
design — the only code is your environment setup at the end.
