# Track 15: Evaluation, Observability & Safety

The track that makes everything before it production-grade rather than a
demo. Evaluating a system whose output is free-form text is genuinely
hard and needs its own methods — eval datasets, LLM-as-judge, regression
testing prompts — plus hallucination detection, guardrails, agent
tracing, and keeping token spend from quietly exploding.
