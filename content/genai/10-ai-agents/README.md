# Track 10: AI Agents

What actually makes a system "an agent" rather than a chatbot — and you
build one **by hand** here, with no framework, so that track 11's
abstractions are recognizable rather than magic. Covers the ReAct loop,
tool schemas and execution, planning, memory, reflection, and the
failure modes (runaway loops, cost blowups) that bite every real
deployment.
