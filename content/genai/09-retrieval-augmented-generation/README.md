# Track 09: Retrieval-Augmented Generation (RAG)

Grounding an LLM's answers in your own documents instead of its training
data alone. Builds a naive RAG pipeline early, then spends the rest of
the track on everything that makes the difference between a demo and a
production system: parsing real documents, hybrid retrieval, reranking,
citations, and honest evaluation.
