# Track 03: Landmark Models — BERT, GPT & Mixture-of-Experts

Track 02 built the transformer block in the abstract. This track shows
the two directions the field split it into — BERT's masked,
bidirectional encoder for *understanding* text, and GPT's causal,
decoder-only generation for *producing* it — why the generative path won
for the chat-and-agents era, and how Mixture-of-Experts architectures
scale parameter count without scaling compute proportionally.
